# Epistemap v0.1.0a3

This alpha compatibility release adds the first indexed graph-operation pass
and a read-only MCP transport while preserving the `v0.1.0a2` graph and typed
confidence contracts.

## Included

- indexed graph views and shared-index diagnostics;
- linear-time bridge-node analysis and faster batch epistemic/Bayesian reports;
- reproducible, sanitized benchmark artifacts and performance roadmap;
- transport-neutral MCP tools plus newline-delimited stdio JSON-RPC serving;
- MCP `initialize`, `tools/list`, and `tools/call` support;
- compatibility tests for Epistemap and consuming repositories.

## Boundary

MCP tools are read-only derived analyses. Epistemap does not decide truth,
promotion, or domain policy. Host authentication and policy-context enforcement
remain the responsibility of consuming systems and MCP hosts.

## Compatibility

The `v0.1.0a2` graph and typed-confidence formats remain readable. Consumers
may update immutable Git pins to `v0.1.0a3` to receive the optimization and MCP
implementation.
