# Epistemap v0.1.0a1

This alpha release establishes the first portable confidence-assessment
contract used by GroundRecall and Didactopus.

## Included

- typed, bounded, provenance-bearing `ConfidenceAssessment` models;
- distinct missing and explicit-zero semantics;
- node and edge assessment collections with lineage helpers;
- JSON, JSON-LD, and Cytoscape assessment preservation;
- assessment-readiness validation and legacy mapping-policy diagnostics;
- initial calibration utilities and typed Bayesian weighting precedence;
- compatibility readers for legacy scalar graph confidence;
- an audited cross-repository implementation roadmap and status report;
- fair-play detective-corpus tooling, fixtures, static interfaces, and
  participant-result exclusion rules developed concurrently.

## Compatibility

Legacy scalar graph confidence remains readable. New producers should write
typed assessments and declare any compatibility down-conversion policy. This
release does not start the removal clock for legacy fields.

GroundRecall and Didactopus should depend on the immutable Git tag
`v0.1.0a1`. A package-index publication is not part of this release.

## Known gaps

- full cross-repository golden-fixture matrix;
- reconstructable, deduplicated Bayesian evidence ledger;
- complete calibration eligibility policy;
- consumer migration commands and compatibility releases;
- documented legacy-field deprecation cycle.
