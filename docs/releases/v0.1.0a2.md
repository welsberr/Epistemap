# Epistemap v0.1.0a2

This alpha compatibility release completes the shared confidence-overhaul
foundation used by CiteGeist, GroundRecall, and Didactopus.

## Included

- installed cross-repository compatibility matrix and fixtures;
- reconstructable evidence-ledger conversion with typed assessment weighting;
- Bayesian posterior reports backed by ledger evidence under declared policy;
- calibration utilities for probabilistic confidence dimensions;
- explicit preservation of missing versus explicit-zero confidence values;
- compatibility readers and diagnostics for legacy scalar graph confidence;
- W13 release plan, unresolved legacy-data notes, and deprecation-clock policy.

## Compatibility

Legacy scalar graph confidence remains readable. New producers should write
typed assessments with explicit dimensions, method provenance, basis records,
and policy identifiers.

GroundRecall and Didactopus should update their immutable Git dependency pin to
`v0.1.0a2`. A package-index publication is not part of this release.

This release starts the compatibility release line, but removal of legacy fields
still requires a later release plan that confirms downstream consumers have
migrated.

## Known unresolved legacy data

- scalar graph `confidence` values without a mapping policy remain ambiguous;
- legacy zero values in downstream stores may mean either explicit zero or a
  missing/defaulted value and must not be rewritten without migration reports;
- retrieval relevance, citation count, graph topology, and topic membership are
  not source reliability or claim truth.
